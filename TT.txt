주의사항
- 길면 안된다. 중요한 내용만 짧은 문장으로 작성.
- 중요한것, 어필하고 싶은거 -> 앞에 나와야됨.
- 앞쪽은 짧게 요약된 것을 배치, 뒤쪽은 상세하게 서술.
- 영상 정보를 잘 사용해야 함. (OBS)

PPT내용
1. 제목 페이지
- 게임 제목, 자기 이름
2. 목차
- 페이지 번호도 넣는 것을 추천
3. 개요
- 제목, 게임주제, 게임특징(장르,게임방식) 한줄로 간략하게
- 엔진, 툴들의 버전
- Git 리포지토리 주소
4. 티저 영상 (순서 고려)
- 10~15초 정도. 게임 특성 파악용 영상
5. 기능 소개
- 각 구현 기능별 간단 소개 (한페이지안에, 구현했다 정도)
- 기능별 영상(gif같이 자동 재생되고 루프되는 영상)
6. 풀영상
- 게임 시작부터 끝까지 보여주거나 한 세션 플레이를 보여줄 수 있는 정도.
- 긴 영상이라서 영상이 재생되는 부분이 어떤 내용을 설명하는지를 쉽게 알 수 있어야 한다.
7. 기능 상세 소개
- 참고 자료에 가까운 부분
- 진짜 상세하게 (소스코드를 직접 보여주거나 리포지토리 파일 링크 추가)
